# 宿主启动与代理

## 职责

承载协议宿主、应用宿主的启动、配置加载、代理与产物 freshness 校验。

## 对外入口

- `protocol-host.ts` 导出按绑定启动协议宿主的入口；`app-host.ts` 导出应用宿主启动入口。
- `proxy.ts` 导出协议宿主、应用宿主与本地预览共用的代理中间件；`freshness.ts` 导出产物摘要校验。

## 允许依赖

协议包、产品包只经清单和包产物读取；只在测试工具进程运行，不进入产品构建。

## 本地约束

`packages/e2e/host/` 只放宿主入口页面与配置；代理、启动与配置解析逻辑保留在本模块，由 test-tools-unit 覆盖，browser 用例提供真实 Chromium 证据。

## 子模块

无。
